So I’ve finally finished my personal site after lots of trial and error. And hi, I'm Ngo Duc Hoang Son.

The idea of this site came around 2021, I was learning web development and wanted to try coding a site on my own. And a personal site seemed to be a great idea :).

Since that time, i have built several versions of the site using difference frameworks like [Next.js](https://nextjs.org/), [Waku](https://waku.gg/) and [Sveltekit](https://svelte.dev/docs/kit/introduction). But it seems I don't really comfortable with some aspects of these frameworks and also the target of my site is low maintaining cost, and yeah, these frameworks change pretty rapidly.

Now, in 2026, while learning Rust and looking for a project to practice my skills, my personal site became a great experimental specimen (again :D). The idea was to build the site from scratch using Rust: no framework, no unnecessary updates, and hopefully keep it running for the next 100 years. And the result has been great, the site finally came to life.

You can read about how I built the site in the [Colophon](/colophon/) and hopefully it gives you some ideas to build your own static site generator.
